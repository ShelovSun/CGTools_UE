# AssetsManagerForUE：UE 资产发布与使用

## 服务器发布目录

资产的 Icon、FBX 与 UE 发布包位于项目的 `Assets` 目录；动作库统一位于同一项目的 `Animations` 目录。UE 最终资产放在每个资产根目录的 `UE/Content` 下，并完整保留它们在项目 `Content` 中的相对路径。

数据库地址统一取自设置窗口打开的 `Y:\MCCTools\config\ShotManager_config\commonSetting.json` 的 `host` 字段。当前应配置为 `"host": "smnas.diandian.info"`，PostgreSQL 端口仍为 `5432`。资产页、场景页、原生后端和发布插件不再使用写死的服务器地址。缺少有效 `host` 时会提示配置错误；下一次数据库连接会重读配置，因此修改 JSON 后刷新数据即可使用新地址。数据库地址修改不会改变 `rootPath`、MCCTools 或 Y: 文件路径。

以 `GuoWang` 为例：

```text
Y:\MCCProject\S01\Assets\Characters\GuoWang\
├─ Icon\                         # 旧版缩略图，继续使用
├─ FBX\                          # 旧版 FBX，继续使用
└─ UE\
   ├─ asset_manifest.json        # 可选；指定卡片拖放时使用的主资产
   └─ Content\
      └─ Assets\Characters\GuoWang\
         ├─ BP_GuoWang.uasset
         ├─ SK_GuoWang.uasset
         ├─ SK_GuoWang.uexp      # 若存在，必须一并发布
         ├─ Materials\...
         ├─ Textures\...
         └─ Action\...
```

加载时会镜像复制为：

```text
<当前工程>\Content\Assets\Characters\GuoWang\...
```

不能在发布后移动或改名 `.uasset`，因为材质、骨架、蓝图等内部引用使用 `/Game/...` 包路径。源资产必须使用和目标工程兼容的 Unreal Engine 版本保存。

## 可选主资产清单

如果一个发布目录里有多个 Actor 蓝图或网格体，可在 `UE/asset_manifest.json` 明确指定拖放主资产：

```json
{
  "schema": 1,
  "mainObjectPath": "/Game/Assets/Characters/GuoWang/BP_GuoWang.BP_GuoWang"
}
```

不提供清单时会自动按以下优先级选择：

```text
Actor Blueprint > StaticMesh > SkeletalMesh
```

## 卡片状态

切换到表单显示后，单击【资产】页的【模型状态】【绑定状态】，或【场景】页的【状态】，即可打开下拉菜单并修改数据库。模型/场景状态提供【未开始】【制作中】【已完成】【UE】，绑定状态提供前三项，与 Maya 版一致。保存使用当前登录账号，项目和类型与当前显示的数据对应；后台提交成功后立即更新单元格及颜色，搜索或切换显示方式后仍保留新状态。保存期间暂时禁用状态编辑，项目/类型正在加载时也不可编辑，避免误改其他项目的数据。

数据库无写入权限、连接失败、记录不存在或状态已被其他人修改时会弹窗说明，原状态保留；刷新后可重试。状态修改仅更新对应状态字段，不会改动制作人、备注或其他状态列。

表单模式还支持以下编辑操作，与 Maya 版保持一致：

- 双击【中文名】弹出文本输入框，按回车或移开焦点保存，按 Esc 取消；可清空中文名。成功后同步更新表格、缩略图和当前预览的中文名。
- 单击【模型制作】【绑定制作】打开按部门分组的人员选择面板，输入姓名可实时搜索，点击人员即保存。场景页的【中文名】【制作人】也支持相同操作。
- 人员名单与 Maya 共用 `Y:\MCCTools\config\ShotManager_config\commonSetting.json` 的 `user_list`，格式为 `{部门: [姓名, ...]}`。打开人员面板时后台重读配置；读取失败会在面板中显示原因，关闭后可重新打开重试。

中文名和制作人编辑沿用状态编辑的保存与失败回退机制，只更新对应数据库字段；资产英文名和磁盘目录不变。列表重建、切换显示模式或开始刷新时会取消尚未提交的编辑，已提交的修改按原项目、类型和资产保存，避免写入其他同名资产。

通过【静态网格体发布】或【骨架网格体发布】成功发布服务器文件后，对应数据库记录的模型状态自动更新为 `UE`。静态网格体使用 `scene.status`，骨架网格体使用 `asset.mod_status`；新建记录和覆盖发布均适用，备注与绑定状态保留。刷新【场景】或【资产】页后，表格中的 `UE` 状态显示为蓝色背景（`#0055AA`）和白色文字（`#FFFFFF`）。

缩略图右上角的亮绿色“UE”角标直接读取数据库：【资产】页读取【模型状态】（`asset.mod_status`），【场景】页读取【状态】（`scene.status`）。值为 `UE` 时显示，其他状态或空值时隐藏。读取到数据后即可显示角标，无需等待目录扫描；手动修改状态并保存成功后，角标立即跟随更新。修改绑定状态不会影响角标。

“UE”角标表示数据库记录已标为 UE 发布状态。【资产】页的【加载资产】是否可用，继续单独检查发布目录里是否有 `.uasset` 或 `.umap` 主包。数据库状态为 `UE`，但目录为空、只有 `.uexp`、`.ubulk`、`.uptnl` 等附属文件，或暂时无法确认主包时，角标仍显示，【加载资产】则为灰色。

悬停卡片可以查看具体原因。资产页和场景页的后台检查优先处理当前点击的资产，再检查可视区域内的资产，最后检查其余筛选结果。滚动、筛选和窗口尺寸变化会重新调整待检查顺序；筛选掉的未执行任务会移出队列，已经开始的文件 I/O 完成后再按新顺序继续。缩略图模式和列表模式均支持。【资产】页排序、搜索和切换显示方式继续复用缓存，点击【刷新】重新检查，主动加载前还会再次核对源文件。

底部状态线表示当前工程的加载状态，与右上角“UE”标记独立：

- 红线：尚未加载、没有 UE 发布包，或者加载/注册失败。
- 橙线：部分文件、正在加载、路径冲突，或包内没有可直接放入关卡的资产。
- 绿线：包已在当前工程中，并已找到可拖放的主资产。
- 加载过程中缩略图上显示按字节计算的进度。

目标工程中出现同名但不同内容的文件时，工具会停止并显示冲突，不会静默覆盖。复制中途失败时，只回滚本次新建的文件。

## FBX 预览与动作库

多皮肤资产按以下配对规则显示：

```text
Icon\<资产名>_<皮肤名>.png
FBX\<资产名>_<皮肤名>.fbx
```

发现至少两套有效配对时，预览器不再显示可能包含全部皮肤的汇总 FBX，而是默认显示自然排序后的第一套皮肤。可用视口左右箭头或底部皮肤缩略图切换；切换后，动作库中选中的动作会重新套用到当前皮肤 FBX。三维预览显示有限地面网格，右下角按钮可在 FBX 三维预览与 Icon 图片预览之间切换。

动作库显示【名字】【修改日期】【大小】三列，点击表头可以排序。右侧底部不再放置【加载资产】与【Import FBX】按钮，这两项功能继续保留在资产卡片右键菜单中。

动作列表递归读取 `Y:\MCCProject\{项目}\Animations\{类型}\{资产名}\Action` 中的 FBX，不再从 `Assets` 下的旧 Action 目录读取。右键依次提供【打开文件夹】【加载动作】【导入动作FBX】。

【加载动作】只在该 FBX 同目录存在同名 `.uasset` 时可用。例如 `BaSiTeV4_Walk.fbx` 对应 `BaSiTeV4_Walk.uasset`。点击后将动画包及存在的同名附属文件复制到当前工程的 `/Game/Assets/{类型}/{资产名}/Action`，刷新 UE 资源索引并在内容浏览器中定位动画。原来的【导入动作】已改名为【导入动作FBX】，继续通过 FBX 导入动画。

旧版发布工具仅修改 `.uasset` 文件名，包内动画仍使用原名，UE 会将其过滤出内容浏览器。新版发布工具会以正确名称保存独立副本；【加载动作】也会兼容旧文件，先备份工程内原文件到 `Saved/CGTools/ActionLoading/Backups`，再修正包内对象名并保存，服务器文件不变。重复加载会通过源文件及本地文件的内容校验识别修复结果；如果任一文件之后被修改，仍按冲突处理。

当前工程的目标资产目录中没有骨架网格体时，会询问是否先加载资产。选择【是】后，读取服务器 `Assets/{类型}/{资产名}/UE/Content` 中的发布包，并与动作一起后台复制；服务器没有可用的 UE 发布包时弹窗报错。选择【否】则取消。工程内同名但内容不同的文件会报告冲突，不会自动覆盖；复制失败会回滚本次写入。

## 使用方式

1. 在【资产】页右键点击卡片，确认【加载资产】可用后选择该命令。
2. 底部状态线变绿后，按住卡片拖到 Level Viewport 内，在目标位置松开。
3. 原来的【Import FBX】、动作 FBX 导入、FBX 预览和场景页仍可照常使用。
4. 【蓝图】页按服务器文件夹显示分类；点击分类内任意卡片的【加载蓝图】，都会完整加载该分类，避免关联蓝图缺失。

## C++ 组件库

【组件】页读取：

```text
Y:\MCCTools\src\UE574\CppComponent\<分类>\<组件名>\
```

例如：

```text
Y:\MCCTools\src\UE574\CppComponent\排队小人\CrowdQueueRuntime\
├─ CrowdQueueRuntime.uplugin
├─ CrowdQueueRuntime.png          # 卡片图标；与组件文件夹同名
├─ Source\...
├─ Binaries\...
├─ Content\...
└─ Resources\...
```

左侧显示 `CppComponent` 下的一级分类，右侧每个直接子文件夹是一张组件卡片。点击【加载组件】后，整个组件目录会复制到：

```text
<当前工程>\Plugins\<组件名>
```

组件卡片右键菜单中的【使用说明】会查找组件根目录下的 `.md` 文件；如果有多个文档，按文件名排序并显示第一个。如果没有 Markdown 文档，工具会弹窗提示联系组件制作者。

使用说明会在组件卡片区右侧的可关闭面板中显示，支持 Markdown 文字格式、本地图片、GIF 动画和可点击链接。文档中的相对媒体路径以 `.md` 所在目录为基准；例如 `![操作演示](images/demo.gif)`。面板右上角的【外部打开】仍可调用系统默认 Markdown 程序。

复制成功后工具会询问是否立即重启 UE。选择【是】时会先显示 UE 的未保存内容对话框，然后退出并重新打开当前 `.uproject`。如果工程中已经存在不同版本，工具会先暂存服务器版本，等 UE 完全退出后再替换；原版本备份在：

```text
<当前工程>\Saved\AssetsManagerForUE\ComponentBackups
```

组件卡片只负责安装编辑器/运行时插件，不能拖入关卡。组件目录必须在根部包含唯一、有效的 `.uplugin` 描述文件。

## 原生拖放桥

精确落点由 `CGToolsAssetBridge` 编辑器插件负责。源码位于：

```text
UE574\Plugins\Marketplace\CGToolsAssetBridge
```

插件必须针对 UE 5.7 编译、部署并启用。若未启用，最终资产仍能加载进工程，但拖放会明确提示缺少插件，不会使用不准确的摄像机前方生成方式。
